# Third-party 3D assets

The source code in this repository does not change the licenses of the model
files below. Keep this notice and the in-product attribution links when
redistributing the project. None of the original creators endorse Brand
Anything.

All four browser files were repackaged as self-contained GLB files, flattened,
welded, pruned, limited to 1024 px textures, converted to WebP where applicable,
and encoded with Meshopt compression. Geometry simplification was disabled.
